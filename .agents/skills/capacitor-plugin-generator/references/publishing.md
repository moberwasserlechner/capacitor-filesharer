# Publishing

Generated plugins are candidates for review. This skill may run publishing
checks and dry runs, but must not publish for real.

## Package Fields

Verify `package.json` contains:

- `name`
- `version`
- `description`
- `author`
- `license`
- `repository`
- `files` including `android/`, `ios/`, `src/`, `dist/`, and docs
- `main`, `module`, `types`, and `unpkg`/bundle fields matching the generated
  build output
- `peerDependencies` with compatible `@capacitor/core`
- `devDependencies` for Capacitor, docgen, TypeScript, lint, and native verify
  tooling
- `capacitor` plugin metadata when generated by the template

## Documentation

Use JSDoc in `src/definitions.ts` as the source of truth:

```bash
npm run docgen
```

Do not hand-write API tables that duplicate generated docs. Add only human
review notes, setup requirements, permissions, platform caveats, and sample
usage around generated docs.

## Pre-Publish Checklist

Run:

```bash
npm run fmt
npm run lint
npm run build
npm run docgen
npm run verify
```

Check:

- No placeholder package names, repo URLs, authors, or descriptions.
- Version is correct for the release plan.
- README documents permissions, configuration, platform support, and manual app
  setup.
- Native dependencies and minimum platform versions are intentional.
- Sample app has been run for web and, when possible, native platforms.
- A human reviewed the generated native code.

## Dry Run Only

```bash
npm publish --access public --dry-run
```

Do not run a real `npm publish` from this skill.
